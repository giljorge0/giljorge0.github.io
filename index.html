Digital Brain

A provenance-aware neuro-symbolic memory system that reads your writing, finds the gaps, and thinks alongside you.

Started from a corpus of 500k words of philosophical writing with nowhere useful to live. The core thesis: retrieval is not enough — a personal knowledge system needs memory formation, maintenance, and gap detection, not just search.

The system ingests org-mode files, PDFs, LLM chat exports, Kindle clippings, and YouTube history into a graph of atomic ideas. A nightly consolidation loop deduplicates, detects contradictions, and decays stale nodes. A gap agent surfaces orphaned ideas, depth gaps (highly-referenced stubs), one-sided claims with no steel-man counterargument, and reading recommendations via Perplexity's live search. A query planner routes questions through symbolic graph traversal, semantic vector search, or temporal filtering depending on what is asked.

The engineering challenge that turned into a real learning moment: building the 30k-note "omni" graph crashed the machine. Diagnosis — 450,000 individual SQLite fsync calls plus an O(n²) cosine similarity matrix held in Python dicts (~450 MB) instead of NumPy arrays (~46 MB). Fix: batch transactions, numpy.argpartition for top-K without materializing the full above-threshold list, WAL journal mode.

Emergent Communication & Universal Language

What does a communication channel need to be for the receiver to know when a message is corrupted?

A two-part research programme. The theoretical essay proposes deriving a universal language from multilingual embedding spaces rather than linguistic intuition — treating the interlingua that emerges from multilingual seq2seq models as a window onto a language-independent world of ideas. The argument: languages currently partition the concept space suboptimally; a speaker-count-weighted centroid vocabulary would lower the entry barrier for every native language while making untranslatable concepts — saudade, schadenfreude, wabi-sabi — explicit rather than silently lost.

The experimental report (23 experiments) grounds this in referential games. The central empirical finding is a direct operationalisation of Deutsch (2011): discrete channels fail loudly — wrong-answer entropy rises monotonically with noise — while continuous channels fail silently, staying confident even when wrong. A zero-knowledge proof of communication (ZK metric) verifies that agents are genuinely using the channel without inspecting message content.

Key result from the Shannon Pareto analysis: no protocol dominates on both compression and noise resilience. Message length is the dominant constraint in the full factorial grid search — more than temperature, bottleneck dimension, or production cost combined.

Active Preference Engine

A personal preference-gradient recommender. No API keys, no platform lock-in. Gets better every session.

Fetches content from HackerNews, GitHub, and arXiv, then re-ranks it using a locally-stored preference vector steered by explicit feedback. Two modes: exploit (surface what you like) and explore (map what you haven't seen yet).

Profile vector updated per-item via Rocchio relevance feedback in the same 384-dimensional embedding space as the content. Personalized PageRank runs over a graph of all rated items, replacing the single profile point with a probability distribution that preserves distinct taste clusters without averaging them together. Exploration rate decays exponentially over sessions.

Originality Radar

A real vector-math topological map of human thought. Submit an idea, get scored against every idea ever submitted globally.

Submit any idea — the backend embeds it into a 64-dimensional semantic vector space, runs k-NN against every previous submission, and returns an originality score (0–100), a density label (SATURATED → VOID), nearest existing thoughts, and a drift suggestion for how to push the idea further into unexplored territory.

When 3+ people submit sufficiently similar ideas, a "You Are Not Alone" card synthesises the collective insight. A live WebSocket canvas maps dots appearing in real-time as thoughts come in from anyone connected. The vector space grows denser over time — a VOID idea today can become FRONTIER in six months.

LLM Thinking Effort Visualizer

Live-streamed reasoning depth, a pre-inference complexity predictor, and a cognitive churn score — before and during the call.

A browser tool built on Claude's extended thinking API with SSE streaming. Per response: a bar filling in real time as the model thinks scaled against a pre-inference prediction; a cognitive churn score counting backtrack markers ("wait", "actually", "let me reconsider") per 100 reasoning tokens; and a deceptive-simplicity flag when the predictor expected a short answer but the model churned heavily.

An offline training pipeline fits a Ridge regression from 8 surface prompt features to actual reasoning token counts. The predictor's R² is itself framed as a research finding: a value near zero suggests complexity emerges during generation rather than being legible from the prompt alone.

Debate to Priors

Every persistent argument lives at the prior layer, not the surface layer. This tool shows you the map.

Two people debate life extension. One cites inequality studies, the other cites flourishing studies. They go back and forth for an hour and nobody moves — because each holds an unstated prior about whether death is a feature or a bug. No amount of evidence-trading closes that gap.

The tool extracts implicit confidence assignments from each argument (4–7 atomic propositions per person, each with an inferred confidence 0–100%), scores prior gaps by magnitude, classifies them as empirical (evidence could resolve this) or normative (evidence cannot), and proposes the minimum belief updates each party would need to make for consensus to be reachable. Voice mode captures live conversations in real time. Runs against Anthropic API or locally via Ollama with schema-constrained decoding.

makemore-flow

Name generation as ODE integration through a 2D latent space you can actually see.

Instead of sampling discrete characters one at a time, a point evolves through a continuous 2D "name-space" along a learned vector field, starting from pure noise. A char-level GRU autoencoder maps every name to a point in the plane; a conditional flow matching model learns the velocity field over that space; generation is numerical integration of the ODE from noise to data.

The latent space is 2D deliberately — every name is a point you can plot, the velocity field is visible as arrows, and generation trajectories can be drawn end-to-end. The interpolation figure walks a straight line between two encoded names and decodes each point: "sophia" morphs smoothly into "william" through a sequence of plausible intermediate names.

Physics-Informing Neural Networks

Instead of forcing a network to obey known physics, let it deviate — then distill the deviation into symbolic math.

A research scaffold for the inverse of the standard PINN setup. A minimax pair: an InformedNet fits data plus known physics, an InformingNet proposes the missing-physics correction. The physics loss is decomposed term-by-term (inertia, damping, stiffness, forcing), each with its own confidence weight — a multidimensional Pareto front instead of one scalar λ.

Test system: a driven, damped oscillator with two hidden terms (Duffing cubic stiffness, velocity-squared drag). SINDy-style sparse regression over the implied residual recovers the hidden terms symbolically. Oracle check: exact hidden term → perfect recovery (R²=1.0). PINN residual → R²≈0.87, spreading weight across correlated polynomial terms due to limited phase-space excitation — itself a concrete instance of SINDy's structural non-identifiability problem.

Neuropixels Behavioral Alignment & Neural Circuit Analysis

Building a biological clock from reward-responsive neurons when no hardware sync signal was recorded.

Eight Neuropixels 1.0 probe recordings from two head-fixed mice performing a joystick-pull task for water reward. The last AP channel was flat across all 89 binary files — no TTL pulses, no hardware sync. Phase 1 tested 440+ continuous features (solenoid artefact, MUA envelope, LFP band power, phase-amplitude coupling, reward modulation index). Best result: F1 = 0.12, RMSE = 144 ms.

Phase 2 used spike-sorted anchor units — reward-responsive neurons that fire reliably at a fixed latency after each reward event. Matching behavioral timestamps to anchor spikes via iterative σ-clipping and least-squares warp reduced RMSE to 1.6–18.7 ms across all sessions (10–100× improvement). A three-unit fusion for the hardest session reached 1.62 ms — near the practical floor given Kilosort's ~1 ms sorting jitter.

With alignment secured: 210 good units classified as Motor (21.9%), Reward (56.7%), Suppressed (17.1%), or Unresponsive (4.3%) by Z-scored PSTH thresholds. PCA on the 201-unit PSTH matrix produces a 3D neural manifold where pre- and post-event trajectories occupy geometrically separated regions, indicating sustained post-reward population state change.

Music Genre Classification via Dimensionality Reduction & Causal Analysis

When does a feature selection method pick the right features for the wrong reasons?

Eight mutual information feature selection methods applied to a 10-class music genre dataset (35k tracks): MIM, MIFS, mRMR, CMIM, JMI, DISR, maxMIFS, DMIM. CMIM retains 93.9% of the full-model Macro F1 with only 6 features; MIFS is worst because its unscaled redundancy penalty eventually selects maximally independent but genre-uninformative features.

Causal extension motivated by Suter et al. (ICML 2019): PC algorithm recovers the causal skeleton; do-calculus interventional curves separate causal from confounded associations. Key result — popularity does not causally determine genre. Hip-Hop and Rap are acoustically indistinguishable across all 11 audio features; the classifier is correctly reflecting the limits of available information.

Post-Quantum Mersenne Cryptosystem

A public-key cryptosystem whose security reduces to the hardness of distinguishing a low-Hamming-weight combination from a uniform random string.

Full implementation of Aggarwal-Joux-Prakash-Santha (CRYPTO 2018). Security rests on the Mersenne Low Hamming Combination (MLHC) assumption — analogous to LWE but over Mersenne prime fields. Built incrementally: bit-by-bit encryption → repetition code → Reed-Muller RM(m,1) → KEM with Fujisaki-Okamoto IND-CCA2 transform via SHAKE-256 / SHA-256 random oracles.

Demonstrated the weak key attack — if F, G < √p, continued fractions recover the private key in polynomial time. Reed-Muller vs. Repetition code comparison: RM gives a deterministic correction guarantee and formal proof of minimum distance at the cost of a 127 MB generator matrix; Repetition gives practical deployment via majority vote with δ < 2⁻²³⁹ at λ = 256.

MacroPCA — Robust PCA with Cellwise & Rowwise Outliers

Subspace angle is not an absolute quality metric.

Replication and extension of Hubert, Rousseeuw & Van den Bossche (Technometrics 2019). Three methods compared: ICPCA, MROBPCA, MacroPCA. MROBPCA fails structurally when d > n — MCD requires h > d, and with d = 200, n = 100 the covariance matrix is singular. Documented as an empirical result rather than an implementation bug.

Extension to the 2022 World Bank Development Indicators (253 country aggregates × 45 indicators). MacroPCA separates size-driven anomalies (GDP aggregates) from governance anomalies (Afghanistan, Zimbabwe, Venezuela). On the contaminated matrix, the subspace angle ranking reverses: ICPCA scores better, but this is a measurement artefact — the reference subspace is itself aggregate-influenced. Detection metrics (rowwise sensitivity 1.00) unambiguously favour MacroPCA.

RNA Binding Affinity — CNN + BiLSTM + Attention

Modeling RBFOX1-RNA binding: local motifs via CNN, global context via BiLSTM, interpretability via attention.

RBFOX1 recognises a short 5–6 nucleotide RNA motif, but the full strand influences binding affinity through structural and chemical interactions. CNN captures local binding regions (three convolutional layers, kernels 5/7/9). Bidirectional LSTM captures global 5'→3' and 3'→5' context. Best models: CNN Spearman r = 0.665, BiLSTM r = 0.681.

Attention heatmaps on test sequences show focused attention on the GCA nucleotides in high-affinity sequences; low-affinity sequences produce diffuse, uniform attention — consistent with the biological role of the (U)GCAUG motif. The second attention head mirrors the first exactly, confirming that a single head is sufficient for this localized binding site. Final model Spearman r = 0.679, MSE = 0.314.

Numerical Linear Algebra — Newton-Schulz, QR, SVD, Power Method

Four classical algorithms, implemented from scratch, tested to failure on ill-conditioned matrices.

Newton-Schulz matrix inversion with theoretical proof that residuals satisfy R_{k+1} = R_k², confirming quadratic convergence — which breaks for Hilbert matrices with n ≥ 8 due to extreme ill-conditioning. Householder QR factorisation maintaining machine-precision residuals (~10⁻¹⁴–10⁻¹⁵) across Lehmer and Hilbert matrices up to 100×100. SVD image compression: 1% of singular values (3 of 256) captures 94.08% of the cameraman image's variance.

Spectral condition number estimation via power method + inverse power method (LU): accuracy degrades sharply for Hilbert matrices at n ≥ 12 as the matrix approaches numerical singularity — matching the theoretical prediction that cond₂(H_n) ~ (3.525)^n.
